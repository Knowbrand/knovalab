IMAGE SETUP
Each article references ../images/<slug>.jpg for both the cover image and og:image.
Create an images folder beside the blog folder and add an image for each slug, or edit the image path in the page.
If the image is missing, the cover gradient remains visible and the browser hides the broken image.

IMPORTANT
- Every page includes og:title, og:description, and og:image for insights.html to fetch.

- More articles links point to other included article pages.
