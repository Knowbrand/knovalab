01 — On-Prem Digital Signage

Your Screens. Your Network. Your Control.

Knovalab’s on-premise signage system replaces repetitive USB-based updating with a Windows CMS and an Android or Android TV Player operating across your local network. It is intentionally built around local control—not positioned as another cloud signage subscription.

CONTROL

Windows CMS

Manage screens and media, build and save playlists, choose one or multiple screens, and publish content.

→
DISTRIBUTE

Local Network

Content moves inside the client environment using configured local connection information.

→
PLAY

Android / Android TV Player

Receives synchronized content, stores required files locally, and handles playback.

→
DISPLAY

Business Screen

Presents the synchronized content while the Player continues operating locally.

Operational Flow

From Content to Screen in Three Steps

01 / CREATE

Build the playlist

Add or select media, arrange it in the Windows CMS, and save the playlist for use.

02 / PUBLISH

Choose the screens

Select one or multiple paired screens and send the chosen content through the local network.

03 / DISPLAY

Play it locally

The Player receives and stores the package, then handles playback directly at the display.

A Practical Difference

Updating a Screen Shouldn’t Require a USB Trip

Both approaches can put content on a screen. The meaningful difference is how much repeated physical work is required when content changes.

Traditional USB workflow

  • Edit content
  • Export the file
  • Copy to USB
  • Walk to the screen
  • Replace the content
  • Repeat for another screen

Knovalab local workflow

  • Open the CMS
  • Change or select content
  • Select screen or screens
  • Publish over the local network
